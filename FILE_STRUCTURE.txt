WHERE TO EDIT
-------------
Page design ............ frontend/src/pages/ and frontend/src/styles/
Colours ................ top of frontend/src/styles/base.css
New API call (frontend)  frontend/src/services/httpApi.js (and mockApi.js)
API behaviour .......... backend/src/routes/
Database fields ........ backend/src/models/
Settings ............... backend/.env (copy from backend/.env.example)

Files created after you install / run (not in the zip):
  node_modules/ (root, frontend, backend), frontend/dist/, backend/.env
